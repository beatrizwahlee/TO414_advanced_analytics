SVM In order to have the best SVM model possible, I did a function that runs the support vector machine with all the kernels and the outputs are the accuracy, kappa, and senstivity of each. That makes it easir to choose which kernel to use for the final model.

try_kernels <- function(kernel_name) {
  model <- ksvm(as.factor(y) ~ ., data = train_scaled, kernel = kernel_name)
  predictions <- predict(model, test_scaled)
  cm <- confusionMatrix(as.factor(predictions), as.factor(test_scaled$y), positive = "1")
  
  accuracy <- cm$overall["Accuracy"]
  kappa <- cm$overall["Kappa"]
  sensitivity <- cm$byClass["Sensitivity"]
  
  # Return all metrics
  return(c(accuracy = accuracy, kappa = kappa, sensitivity = sensitivity))
}
